# Spiderboys Trading Pro v9

## Responsive workstation

Version 9 supports two layouts:

- **Compact** — designed for normal browser windows and smaller screens.
- **Desk** — designed for ultrawide monitors with watchlist, chart, Spider AI, and news visible together.

## Major additions

- Responsive Spider AI Command Center
- Live market-session label
- Saved watchlist quote snapshot
- Scanner filters for price, day change, score, news, and positive movers
- Clear distinction between live quotes/news and restricted intraday chart data
- Linked ticker workflow across Scanner, Charts, News, and Trade Plan
