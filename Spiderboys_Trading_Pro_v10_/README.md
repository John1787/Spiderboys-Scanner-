# Spiderboys Trading Pro v10

Professional dockable workstation.

- Collapse Scanner hides the left workspace panel.
- Restore Scanner always remains visible at the top.
- Collapse AI hides the right analysis panel.
- Restore AI always remains visible at the top.
- The chart automatically expands into available space.
- Streamlit's top-left arrow collapses and restores the navigation sidebar.

Upload the contents directly to the GitHub repository root. Main file: `app.py`.
