# Streamlit Upload Guide

Upload the unzipped folder contents to GitHub. Your repository root should show:

- `app.py`
- `requirements.txt`
- `README.md`
- `core/`
- `data/`
- `tradingview/`
- `.streamlit/`

In Streamlit Community Cloud, use `app.py` as the main file path. No secrets are required for the flagship demo release.
